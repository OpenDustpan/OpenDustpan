# RFC 46. Insights: dashboards and reports

Status: draft. A stub opened from the competitor review in the research doc
"IaC and TACOS landscape". It records the gap and first ideas only.

## Problem

Spacelift, Terramate and Atmos Pro show DORA metrics; Scalr reports stale
workspaces and tool versions with bulk upgrade; Terramate and HCP Terraform
show health over time.

## First ideas

- A status overview from the inventory (RFC 26).
- DORA metrics from update and run history.
- Reports: stale units, tool and provider versions in use, blueprint versions
  in use (RFC 14).

## Open questions

- Which of these are views over existing data, and which need new records?

# 1. Record architecture decisions

Status: accepted · 2026-10-08

Changed by:

- ADR 296 extends: an accepted ADR gets a "Changed by" list.

## Context

OpenDustpan is built partly with AI coding agents and, later, outside
contributors. Both need the reasons behind the structure, not only the code.

## Decision

Significant decisions are recorded here as short, numbered ADRs: context,
decision, consequences. An ADR is never edited after acceptance except to mark
it superseded; a changed decision gets a new ADR.

## Consequences

Contributors and agents read `docs/adr/` before changing architecture.

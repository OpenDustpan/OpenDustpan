# @opendustpan/client

A TypeScript client for the OpenDustpan REST API under `/api/dustpan/v1`. The
`clientgen` program writes it from the API description of the server. The
client validates every answer at run time.

The package has no dependency. It needs Node 20 or a browser that has `fetch`.

```ts
import { Client, createFetchTransport } from "@opendustpan/client";

const client = new Client(createFetchTransport({ baseUrl: "https://dustpan.example.com", token }));
const { status, etag, body } = await client.getCapabilities();
```

Do not edit the files in `src`. They carry the header `Code generated by
clientgen`. To change them, change the generator and run `make
clients-generate` in the repository. See `docs/reference/typescript-client.md`.
